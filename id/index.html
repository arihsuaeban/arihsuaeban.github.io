Cara Saya Memimpin Tim

5 rekrutan · jenjang karier baru

Struktur tim & pengembangan

  • Membangun jenjang karier yang sebelumnya tidak ada: Junior, Mid, dan Senior Developer; Junior dan Senior QA.
  • Menyertakan sistem mentoring di setiap jenjang agar engineer tahu cara berkembang.
  • Ikut merekrut 5 anggota tim.
Rotasi engineer lebih cepat

Standar engineering

  • Standar kode berbasis prinsip SOLID.
  • Proses code review yang baku untuk setiap perubahan.
  • Solution template sebagai base code bersama, sehingga engineer bisa pindah proyek tanpa masa adaptasi panjang.
5–7 proyek paralel

Ritme delivery

  • Wrap-up harian: semua orang melihat progres dan tahu apa yang perlu disiapkan esok hari.
  • Pendekatan teknis berbasis konfigurasi sehingga tim BA/fungsional bisa ikut mengonfigurasi fitur — kunci untuk deadline ketat Pertamina.
  • Sharing session hangat di mana satu squad membagikan hal yang dipelajari ke tim lain.
3–4 bulan → 1–1,5 bulan

AI-driven development dengan guardrail

  • Claude sebagai AI pair programmer tim.
  • Setiap perubahan mengikuti file panduan dasar (Markdown) yang sudah ditetapkan.
  • Self-review oleh developer, lalu code review oleh senior developer sebelum merge.
  • Hasil: waktu ke full QA jauh lebih singkat, dan tiap squad bisa mengerjakan lebih banyak proyek paralel.
